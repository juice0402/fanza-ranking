# FANZA新作情報

FANZAの新作・予約作品を毎日自動で集めて、AIのひとことコメントを添えて公開するブログです。
公開サイト: https://fanza-ranking.pages.dev/

## 自動で動くしくみ

1. 毎日 午前0時5分（日本時間。日付が変わった直後）に GitHub Actions が `get_new_releases.py` を実行
2. FANZAの新作・予約を取得 → Geminiでコメントを作成 → `site/src/data/new_releases.json` にためていく
   - あわせて、保存済み作品の出演者・サンプル動画の取り直し、出演者のプロフィール（`actresses.json`）、売れ筋ランキング上位6本（`ranking.json`）も更新（この3つはGeminiを使わない）
3. データが更新されると Cloudflare Pages が自動でサイトを作り直して公開
4. AIコメントが付かなかった作品には、毎日 午前0時20分ごろ（日本時間）に Claude の予約タスクがコメントを書き足します（手順は [docs/claude-comments.md](docs/claude-comments.md)）
5. 毎週月曜 午前0時50分ごろ（日本時間）に、Claude の予約タスクが、前の週（月〜日）に発売された作品の「週のまとめ記事」を書いて公開します（手順は [docs/claude-roundups.md](docs/claude-roundups.md)）

## サイトにある、また来たくなる機能

- ☆お気に入り: 作品・出演者・メーカーに ☆ を付けると「お気に入り」ページに集まり、登録した出演者・メーカーの新作と予約も出ます（保存はその端末のブラウザの中だけ）
- 発売日カレンダー: iPad・iPhone・Googleカレンダーで購読すると、発売日が自動で入ります（出演者・メーカーごとも可）
- 出演者から探す: 名前・年齢・身長・スリーサイズ・カップで検索できます。顔写真つきで、FANZAでの全作品へのリンクもあります（FANZAに載っている情報だけを使うので、数字が載っていない人は、数字の条件で探すと出ません）
- 作品ページのサンプル動画: FANZAのサンプル動画があれば、パッケージ画像のかわりに動画を出します（パッケージ写真は、サンプル画像の下に、別の欄で大きく出します）
- 売れ筋TOP3: トップに、FANZAの人気順の上位3本を出します（「VR作品を隠す」を押すと、VRを除いて次の順位から差し替えます）
- 作品を探す: タイトル・出演者・メーカー・ジャンル（商品タグ）で絞り込めます。作品ページのジャンルをタップすると、そのジャンルの作品が出ます
- VR作品を隠す: スイッチ1つで、一覧と検索からVR作品を外せます（その端末のブラウザの中に覚えます）

## 運営の手引き（iPad・スマホでOK／ターミナルは不要）

**今すぐ更新したいとき**: GitHub のこのリポジトリ → `Actions` → `Daily FANZA Update` → `Run workflow` → 緑のボタン。
終わったら、そのRunのページの上に出る「FANZA更新の結果」で、取得件数とAIコメントの成功数が確認できます。赤い × が付いたら、ログをそのままClaudeに貼ってください。
※ AIコメント（Gemini）の無料枠は1日20回ほどです（日本時間の午後4時に新しい1日が始まります）。**手動実行は1日1回まで**にしてください。手動で動かした分だけ、次の0時5分の自動実行で使える枠が減ります（足りない分は、そのあと Claude が書き足します）。

**サイトを変えたいとき**: Claudeに頼む → Claudeがプルリクエスト（変更の提案）を作る → プレビューのURLで見た目を確認 → 問題なければ `Merge pull request` → `Confirm merge`。
プルリクエストの画面で、緑の ✓（CI）が付いているのを確認してからMergeしてください。赤い × のときはMergeせず、Claudeに伝えてください。

**必要な設定（GitHub の Settings → Secrets and variables → Actions）**

| 名前 | 中身 |
|---|---|
| `API_ID` | DMM アフィリエイトAPIのAPI ID |
| `AFFILIATE_ID` | アフィリエイトID（`〜-990` のような末尾が990〜999のもの） |
| `GEMINI_API_KEY` | Google AI Studio で作ったAPIキー（無くても動くが、コメントは定型の代替文になる） |

これらは公開しないでください（このリポジトリは公開されています）。
