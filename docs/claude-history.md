# Claude による「女優の歩み」の紹介文（毎日のコメントの予約タスクの中で）

女優のページの「歩み」（年表）のいちばん上に、2〜3文の紹介文を出す（運営者の希望「紹介文いいじゃん！オリジナルだし、差別化もできるし、SEOにも強そう」。2026-10-27）。
**毎日 0:20 のコメントの予約タスクが、コメントを書いたあとに5人ずつ書く**（`docs/claude-comments.md` の手順4のあと）。同じPRに入れる。

- 数字は `scripts/actress_history.py` が FANZA公式のAPIで数えたもの（`actress_history.json`）。紹介文は `actress_stories.json` に入る（`scripts/claude_history.py apply` だけが書く。手で編集しない）
- 紹介文の無い人（このサイトの本数が多い順）→ 90日より前に書いて、そのあと数字が集め直された人の順に、`list` が出す。歩みのデータがまだ無い人は出ない
- 画面に「AI」という言葉は出さない。フッターの「自動で作成・正確さは保証できない」の注記がこの文にもかかる

## 手順（コメントの手順4のあと）

1. `python3 scripts/claude_history.py list`（5人。`"count": 0` なら何もしない）
2. 下の「書き方」で、1人ずつ書き、`[{"name": "名前", "text": "紹介文"}]` のJSONファイルにする（作業用の置き場に。リポジトリには入れない）
3. `python3 scripts/claude_history.py apply ファイル.json`（問題があると何も書き込まれず、理由が出る。直してもう一度）
4. コメントと同じPRに入れる（変わってよいファイルに `site/src/data/actress_stories.json` が加わる）。報告に「紹介文 N人」を1行

## 書き方

- 90〜200文字・2〜3文。名前は「〇〇さん」で1回入れる
- **使ってよいのは `list` の facts の数字と名前だけ**（本数・年・月・何本目・メーカーと本数・共演の本数・ジャンルの本数）。facts に無い数字は `apply` が断る。作品のタイトルは出さない・書かない
- 「デビュー」と書かない。いちばん古い作品は「FANZAでいちばん古い作品」「FANZAの作品は2018年4月から」のように書く（配信より前の作品があるため）
- 私生活・確かめられないことは書かない（結婚・引退・卒業・復帰・本名・出身・年齢・事務所・専属・うわさ。`apply` が断る）。「人気」「代表作」「No.1」のような評価も書かない
- 何が読み取れるかを、数字で具体的に書く。たとえば: どの年に本数が多いか・メーカーが1社に集中しているか、何社に分かれているか・VR やベスト・総集編の多さ・よく共演している人。0本の年があっても、理由は書かない（数字では分からない）
- 書き出し・文の形を人ごとに変える（ほかの人と同じ書き出し8文字は `apply` が断る）。「〇〇さんのFANZAの作品は」で始めてばかりにしない
- 禁止語・記号・あおり言葉はコメントと同じ（`claude_comments.text_problems`・`HYPE_WORDS`）

例（数字は例）:
- 「河北彩花さんの作品は、2025年がいちばん多い59本で、そのうち54本がエスワン ナンバーワンスタイルでした。FANZAでいちばん古い作品は2018年4月で、100本目は2023年9月。VR作品は24本あります。」
