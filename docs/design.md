## デザイン（`site/src/styles/site.css`・`components/`・`layouts/Base.astro`）

- **押せるもの（ボタン・チップ・切り替え・入力欄）の枠と地は `--edge`・`--fill`**（運営者の指摘「黒いボタン系が背景と同化して見づらい」。2026-10-06。枠は背景との明るさの差3:1以上）。パネル・表の罫線は `--line` のまま。新しいボタンを足すときも、この2つを使う
- **説明文は短く**（運営者の希望「長すぎる説明文は誰も読まないし、サイトを圧迫する」。2026-10-06）: 見出しの下の説明は1文まで。出演者・メーカー・月・ジャンルのページの長い紹介文は画面に出さず（説明文 description にだけ使う）、「48本（2025年5月〜2026年10月発売）」「116本・10月3日〜10月20日発売」の1行（`items.js` の `shortSpan`）。規約・正直さのための注記（○日の時点・自動で作成・公式サイトで確かめて など）は短くしても消さない
- **あとから出てきて画面がずれる作りにしない**（運営者の「ほかのページでも同じ現象を直して」。2026-10-07）: JavaScript が使えるときだけの部品は、`hidden` にしてスクリプトが出すのではなく、はじめから出しておき、使えないときだけ CSS（`html:not(.js) …`。`js` の印は `Base.astro` の `<head>` が付ける）で隠す（VR・単体のスイッチ・お気に入りのボタン・運命の作品（候補がそろうまで「まわす」は押せない）・予約の「もっと見る」・作品検索・女優検索）。スイッチの押した見た目は `html.hide-vr`・`html.only-solo` でもすぐに出す。データを読んでから出す一覧は、ページを作るときに「はじめの一覧」を入れておく。トップの推しの棚（2026-10-31。前の1行のお知らせの代わり）は、お気に入りの出演者・メーカーがある人（`html.has-favs`）にだけ、はじめから場所を出し、読みこむまでは推しの人数（`--oshi-rows`。4人まで）の行の高さを取っておく。「お気に入り」ページの「まだお気に入りがありません」も、無い人（`html.fav-none`）には、はじめから出す。**セールの「終わったら隠す」（`public/sale.js`）は、ページの先頭にそのまま入れて（`assets.js` の `inlineScript`。`<script id="sale-early">`）、中身が読み込まれるそばから印を付ける**（前は読み込みのあとで隠していたので、その日に終わった特集・作品が、いちど見えてから消えて下がずれた）
- **AIっぽさゼロ**（運営者の「サイト作りの原則」。プロジェクトの `claude/site-principles.md`。2026-10-18）: 絵文字（✨✅🚀 など）・右はしの「›」「→」・「おすすめ・ぜひ・便利・簡単・安心・コツ・しましょう・——」は使わない（`tests/test_ai_style.py`・コメントと記事は `text_problems` が断る）。2026-10-22 から、左はしの色の帯・えらんだものだけ色をぬる四角いボタンの切りかえ（→ 申込用紙の「○」「□」と文字）・行の右はしの小さな「見る」・「新作」「NEW」などのシールや札（→ 文字だけ）も使わない。説明の行は1行（見出しの下は全角24字・小さな注記は28字）まで、出どころ・時点・「FANZAで確かめて」の注記（class `note-source`）は2行まで（`verify_dist.py` が注意を出す）
- **一覧のカードは低く**（2026-10-06）: タイトル2行・ひとこと2行（全文は作品ページ）・FANZAのボタンはカードのいちばん下にそろえる
- **どんな画面の大きさにも**（運営者の希望。2026-10-05）: 3つ並び（TOP3・いま人気の女優・人気のジャンル・運命の作品・今週のデビュー作・誕生日の近い女優）は、どれも「3等分の列」（`--trio-gap`・`--trio-max`）で、中身は列の幅に合わせて大きさが変わる（丸は列の74%、四角・表紙は列いっぱい。順位の数字・名前は `cqi` で少し大きく）。作品の棚・作品検索の結果・週のまとめの注目の作品は、**置かれた場所の幅で列の数を決める**（コンテナクエリ。`site.css` のいちばん下。使えない古いブラウザには画面の幅の予備）。新しい3つ並びや棚を足すときも、この決まりに合わせる。ページの幅は 1180px（1440px〜は1320px、1760px〜は1440px）、パソコンのトップの右の欄は `clamp(300px, 30%, 380px)`。女優のページと読み物も、パソコン（960px〜）ではトップと同じ幅の「左に本文・右に柱」（`site.css` の `.page-cols`。柱に 女優＝プロフィール・イベントの予定・シリーズ／読み物＝この読み物の中身・最初に見るならこの5本・あわせて読む。スマホは変えない。連絡 C-017・#205。2026-10-31）
